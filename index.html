How to install

  1. Click Download for Windows and wait for the file to finish.
  2. Double-click OfflineCoder-Setup.exe.
  3. If a blue “Windows protected your PC” box appears, click More info, then Run anyway.
  4. Wait for the install to finish. The app opens by itself.

The app is not code-signed yet, so Windows shows that warning for new apps. It is expected.

Good to know

Windows only for now. No debugger yet. Linux-only calls such as fork() are not available. Installing new packages with pip or npm still needs internet.
Offline Coder bundles open-source tools (MinGW GCC, OpenJDK, Python, MySQL, MongoDB and freeglut). Each tool stays under its own license and belongs to its owners.
